# Plan 01-01: Root Workspace + TypeScript Config + Shared Types

## Goal
Establish the npm workspace monorepo with root and workspace package.json files, TypeScript configs for both server (NodeNext) and client (Bundler), and identical shared type definitions in both workspaces. After this plan, `npm install` from root resolves all dependencies and both TypeScript configs compile without errors.

## Requirements
INFRA-01

## must_haves
- Root `package.json` with `"workspaces": ["server", "client"]` and `"private": true` exists
- `server/package.json` exists with `fastify ^5.8.2`, `@fastify/cors ^11.2.0`, `tsx ^4.21.0`, `typescript ^5.9.3`
- `client/package.json` exists with `react ^19.2.4`, `react-dom ^19.2.4`, `vite ^8.0.0`, `@vitejs/plugin-react ^6.0.1`, `@types/react ^19.2.14`
- `server/tsconfig.json` has `"module": "NodeNext"` and `"moduleResolution": "NodeNext"`
- `client/tsconfig.json` has `"module": "ESNext"`, `"moduleResolution": "Bundler"`, `"jsx": "react-jsx"`
- `server/src/types.ts` and `client/src/types.ts` both export all 5 types/interfaces: `Team`, `UnitStatus`, `Unit`, `TickDelta`, `GameEvent`
