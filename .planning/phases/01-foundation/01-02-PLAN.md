Create `/Users/aviad/code/ai-code-workshop/server/src/index.ts` with the following exact content:

```typescript
import Fastify from 'fastify'
import cors from '@fastify/cors'

const server = Fastify({ logger: true })

await server.register(cors, {
  origin: 'http://localhost:5173',
})

server.get('/health', async () => {
  return { status: 'ok' }
})

const port = Number(process.env.PORT) || 3000

try {
  await server.listen({ port, host: '0.0.0.0' })
} catch (err) {
  server.log.error(err)
  process.exit(1)
}
```

Key rules for this file:
- Use `import Fastify from 'fastify'` — NOT `require('fastify')` (Fastify 5 is ESM-first)
- Top-level `await` works because server/package.json has `"type": "module"`
- `await server.register(cors, {...})` is idiomatic Fastify 5 (not callback style)
- No `.js` extension needed here because index.ts has no relative imports to other local files yet
