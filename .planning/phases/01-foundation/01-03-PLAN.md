<action>
Create `/Users/aviad/code/ai-code-workshop/client/vite.config.ts` with the following exact content:

```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  server: {
    proxy: {
      '/stream': 'http://localhost:3000',
      '/units': 'http://localhost:3000',
      '/health': 'http://localhost:3000',
    },
  },
})
```

The proxy uses prefix matching — any request whose path starts with `/stream`, `/units`, or `/health` is forwarded to the Fastify server. This avoids CORS in dev because the Vite proxy rewrites the origin.
